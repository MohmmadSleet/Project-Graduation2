سياسة الخصوصية

نحن نلتزم بحماية خصوصية بياناتك الطبية والشخصية بكل أمان ومسؤولية

1. جمع المعلومات

نقوم بجمع بعض المعلومات الأساسية عند استخدامك للمنصة مثل: الاسم، البريد الإلكتروني، بيانات الأعراض الطبية عند استخدام خاصية التشخيص الذكي، وتاريخ الحجوزات، وذلك بهدف تحسين تجربة الخدمة الطبية وربطك بالمختصين.

2. استخدام البيانات

تُستخدم البيانات المدخلة حصراً لتسهيل عملية حجز المواعيد، تقديم استشارات التشخيص الأولي عبر خوارزميات الذكاء الاصطناعي، وتوفير فرص التدريب والتواصل بين الخريجين والعيادات الطبية داخل المنصة.

3. أمان وحماية المعلومات

نطبق أعلى معايير الحماية والأمان الرقمي لضمان سرية البيانات الطبية ومنع الوصول غيرAuthorized أو كشفها لأي طرف ثالث، مع الالتزام التام بالمعايير الأخلاقية لحفظ سرية المريض.

4. حقوق المستخدم

يحق لأي مستخدم طلب تعديل أو حذف بياناته الشخصية المسجلة على المنصة في أي وقت عبر التواصل مع فريق الدعم الفني أو إدارة النظام.
